pyBOAT

A Biological Oscillations Analysis Toolkit

A time-frequency analysis suite tailored for noisy, non-stationary biological signals. Available via an interactive GUI and Python library.

Download / Install Read User Guide

Built for Noisy and Non-Stationary Biological Rhythms

Circadian dynamics, cell-cycle signals, and developmental clocks naturally exhibit time-varying amplitudes and frequencies and are typically confounded by strong trends and noise. pyBOAT bundles the established Morlet wavelet transform with optimal frequency-domain filtering and wavelet ridge detection to tackle the unique challenges of biological time series.

Learn the Theory & See it in Action

Learn about the methodology in our preprint, or watch the hands-on video tutorial to get started with the GUI.

Read Paper Watch Video

Optimal Sinc Detrending

High-pass sinc filter with sharp cut-off periods to eliminate baseline trends without distorting oscillatory dynamics.

Continuous Wavelet Transform

Morlet wavelets tailored for biological scales, complete with cone of influence (COI) tracking and white noise normalized power spectra.

Ridge & Phase Extraction

1D ridge tracking along 2D wavelet spectra to reliably extract instantaneous period, amplitude, and phase across time.

Install & Run with Python

Install into your Python environment via conda-forge or PyPI, then start the interface directly from your shell or use the pyboat package in your Python scripts.

Via conda-forge (recommended)
conda install -c conda-forge pyboat
Via PyPI
pip install pyboat
Launch GUI from Terminal
pyboat Launches graphical interface

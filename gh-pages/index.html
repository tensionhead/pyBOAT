pyBOAT

Biological Oscillations Analysis Toolkit

A time-frequency analysis suite tailored for noisy, non-stationary biological signals. Includes sinc-detrending, continuous Morlet wavelets, and automatic ridge detection via an interactive GUI or Python library.

Download / Install Read User Guide

Built for Non-Stationary Biological Rhythms

Circadian dynamics, cell-cycle signals, and developmental clocks naturally exhibit time-varying amplitudes and frequencies and are typically confounded by noise.

Optimal Sinc Detrending

High-pass sinc filter with sharp cut-off periods to eliminate baseline trends without distorting oscillatory dynamics.

Continuous Wavelet Transform

Morlet wavelets tailored for biological scales, complete with cone of influence (COI) tracking and white noise normalized power spectra.

Ridge & Phase Extraction

1D ridge tracking along 2D wavelet spectra to reliably extract instantaneous period, amplitude, and phase across time.

Install & Run with Python

Install into your Python environment via conda-forge or PyPI, then start the interface directly from your shell.

Via PyPI
pip install pyboat
